# Materiais 75 LAB

Materiais ricos (páginas de captura + PDF) e kits de publicação das peças do agente de conteúdo da ABCCOM.
Publicado em https://projetos.75lab.com.br/materiais/ (GitHub Pages, branch main, raiz).

- `m/<slug>/` página de captura do material; o formulário manda o lead para o Ariuno (`/api/leads/material`, quadro "Comercial · Leads de conteúdo").
- `pecas/<id>/` kit de publicação de cada peça aprovada (textos para copiar e imagens nos tamanhos da ABCCOM).
- Gerado por `~/abccom-agente` (não editar à mão: é sobrescrito).
